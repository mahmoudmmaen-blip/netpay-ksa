# Host privacy policy for Play Store

Upload `privacy.html` to your web server so it is available at:

**https://netgulf.app/privacy**

## GitHub Pages (example)

1. Create repo `netgulf-legal` or use your main site repo.
2. Copy `privacy.html` to the root or `/privacy/index.html`.
3. Enable GitHub Pages → custom domain `netgulf.app`.
4. Verify HTTPS and the URL in a browser before submitting Play Console.

The in-app WebView loads `assets/privacy_policy.html` (same content). Play Console requires the public HTTPS link.
